# II. AWS IAM

* 글로벌 수준 서비스

* 단일 계정 루트 사용자가 위험한 이유

    * 계정 권한을 변경할 수 없음

	* 계정 루트 사용자가 손상되면 전체 AWS 환경이 손상됨

* 계정 루트 사용자를 보호하는 법

    * MFA 추가

	* 새로운 IAM 사용자 생성: 최소 권한 원칙을 적용해야 함

# III. AWS STS(Security Token Service)

* AWS 리소스에 접근할 수 있는 임시 자격증명 토큰 발급: 유출 위험이 있는 장기 자격 증명 대신 사용하여 보안 강화

* 작동 원리

    * 신뢰할 수 있는 사용자나 애플리케이션의 요청을 받아 임시 접근 키, 비밀 키, 세션 토큰을 발급
	
	* 다른 AWS 계정의 사용자나 외부 사용자가 내 AWS 리소스에 제한적으로 접근해야 할 때 해당 Role을 빌려올 수 있게 함

# IV. Policy

* 자격 증명 또는 리소스와 연결될 때 해당 권한을 정의하는 AWS 객체
