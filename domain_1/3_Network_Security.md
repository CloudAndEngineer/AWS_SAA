# 2. Network ACL

  * AWS VPC 내에서 Subnet 수준의 트래픽을 제어하는 Stateless 방화벽

  * 번호가 낮은 규칙부터 우선순위로 평가된다.

  * 인스턴스 수준으로 설정되는 보안 그룹과는 달리, 서브넷 수준으로 설정된다.


# 3. Bastion Host

  * 외부 인터넷과 내부 사설망 사이에 위치해 외부의 직접 접속을 막고 안전하게 내부 서버를 관리하는 점프 서버(게이트웨이)

  * 일종의 프록시 서버이다.


# 4. VPC Endpoint

  * 외부 인터넷망을 거치지 않고 VPC 내부 네트워크를 통해 AWS 서비스나 외부 서비스에 비공개로 직접 연결할 수 있게 하는 가상 디바이스

  * EC2, RDS, ELB 등은 VPC 내부에서 동작하는 서비스이지만, S3, CloudWatch, DynamoDB, API Gateway 등은 그렇지 않다. -> 공인 IP를 이용해 외부에서 접근

  * 예를 들어, EC2 Instance에서 S3 API를 호출할 때 Bastion Host와 NAT Gateway를 이용해 구성한 서비스일 경우 인터넷을 이용해야 한다.




  * Transit Gateway와의 차이점

    * 개별 AWS 서비스에 비공개로 연결하기 위한 VPC Endpoint와는 달리, Transit Gateway는 여러 VPC와 온프레미스 네트워크를 하나로 묶는 중앙 클라우드 라우터이다.


  * VPC Endpoint 종류

    * 인터페이스 엔드포인트

	* 각 서브넷마다 ENI(Elastic Network Interface)를 생성한다.

	* 해당 서브넷 대역 내에서 사용되지 않는 IP 중 하나가 통신용 NI에 새로 할당된다.

    * 일반적으로 프라이빗 서브넷 내부에 위치하며, 다양한 서비스를 지원한다.

	* 작동 예시

	* 도메인 조회: EC2 인스턴스가 AWS 서비스에 접속하려고 VPC 내부 DNS 서버에게 주소 반환을 요청한다.

	* 프라이빗 IP 반환: 'Private DNS' 기능 덕분에 DNS 서버는 퍼블릭 IP가 아닌, 프라이빗 서브넷에 생성된 ENI의 프라이빗 IP를 알려준다.

	* Local 라우팅 적용: 이 IP는 라우팅 테이블의 Local 규칙에 매칭된다.

	* 정상적인 내부 통신: EC2는 같은 VPC 네트워크 안에 있는 다른 컴퓨터에 데이터를 보내듯, 아무런 의심 없이 엔드포인트 ENI를 향해 패킷을 보낸다. ENI는 자기 앞으로 온 이 패킷을 받아서 AWS 서비스 백본망으로 넘겨준다.


	* 게이트웨이 엔드포인트

	* 게이트웨이 엔드포인트를 생성한 뒤 Subnet에서 Routing만 추가로 생성한다. S3, DynamoDB만 지원한다.

	* 해당 서브넷의 라우팅 테이블만 변경된다. 새로운 IP가 할당되지 않는다.

	* 인터페이스 엔드포인트와 달리 전면 무료이다.


# 5. PrivateLink

  * 퍼블릭 인터넷 노출 없이 가상 서버(VPC), AWS 서비스, 온프레미스 환경 간에 안전하고 비공개로 연결해 주는 네트워킹 기술

  * 사용자의 VPC 내에 탄력적 네트워크 인터페이스(ENI)인 인터페이스 엔드포인트를 생성해 내 것처럼 접속할 수 있다.
